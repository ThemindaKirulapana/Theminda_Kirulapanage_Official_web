## Portfolio page-view counter

The footer can display page views using GoatCounter. To enable it:

1. The GoatCounter site code (`renukatheminda`) is configured in `index.html`.
2. Open the portfolio with Live Server or deploy the site. The counter tracks and displays views for the current page; the portfolio home page is counted at `/`.

GoatCounter is a third-party analytics service; see the privacy policy.
